# Fictional Brands

**Fictional brands, real feelings.**

Open-source landing pages for brands that don't exist, each built around a real brand idea: a name, a play on words, a moment worth sharing. Every page speaks to a real person, ships in English, French and German, and is a complete project you can clone, run and make your own.

Free to use, MIT licensed.

## Inside the pages

### Hush

[![Hush sections: the agent, the benefits, how it works and how a quieter week feels](previews/hush-sections.jpg)](landing-pages/hush)

A bright SaaS page. The word "meetings" gets crossed out in the title, the agent's jobs arrive one by one, three animated illustrations explain the product, and every picture is a file you can swap.

### AUREN

[![AUREN sections: the aura reveal, the 3D bottle, the benefits and the purchase block](previews/auren-sections.jpg)](landing-pages/auren)

An editorial skincare page. "Aura renewed" turns into the brand name, a 3D bottle follows the scroll, and a before and after slider shows the benefits.

## Run locally

Each folder in `landing-pages/` is an independent project. Requires Node.js 20+.

```bash
cd landing-pages/hush   # or landing-pages/auren
npm install
npm run dev
```

For a production build, run `npm run build` (output in `dist/`). Hush also has `npm test`, which checks its pictures and needs Node.js 22.6+. Each project's README explains its structure and how to rebrand it.

## What every page has

1. A fictional brand with a short name and a real idea behind it
2. One moment worth recording as a GIF
3. Copy written for one real person, not for "users"
4. English, French and German
5. The same structure: all content in `src/content/site.ts`, translations in `src/content/i18n.ts`, one file per section
