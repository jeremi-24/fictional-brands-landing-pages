# Contributing

Thanks for wanting to help.

## Fixes and improvements

1. Open an issue describing the problem or the idea.
2. Fork the repository and create a branch.
3. Work inside the project folder (`landing-pages/<project>`) and check that `npm run build` passes.
4. Open a pull request: one topic per pull request, with a screenshot when something visual changes.

## Translations

Translations live in `landing-pages/<project>/src/content/i18n.ts`. Native speakers reviewing French or German, or adding a language, are especially welcome. The file explains how arrays are matched by position.

## Ground rules

- Keep the brands fictional: no real company names, logos or people.
- No text over product photos.
- Respect `prefers-reduced-motion` for any new animation.
- Images you add must be yours or free to redistribute; say where they come from.
